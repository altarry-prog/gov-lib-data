# gov-lib-data

전국 공공도서관·문화 분야 **공개 자료**를 시군구 단위로 모아, 지역 정책 근거(브리핑·정책 제안·공모 분석)에 바로 쓰도록 쌓는 저장소입니다.
수집은 GitHub Actions가 하고, 이 저장소에는 **결과(집계·목록·기준일)** 만 남깁니다.

## 저장 원칙
1. **결과는 여기(GitHub)**: 집계·지표·조례 목록·기준일 기록. 파일 하나 100MB 금지, 저장소 전체 1GB 아래 유지.
2. **덩어리는 GitHub 릴리스**, 꼭 필요한 원본만 외부 저장소(Cloudflare R2 등)에 둡니다.
3. **다시 받을 수 있는 원본은 저장하지 않습니다.** 대신 집계 코드를 남겨 누구나 다시 만들 수 있게 합니다.

## 모든 자료에 붙는 것
- 원천 기관·원천 식별자(법규ID, 시설코드 등)·원천 주소
- 수집일과 원천 기준일
- 이용 조건(공공누리 유형, 이용허락범위)

인증키·개인정보(이름·전화번호·좌표가 개인을 가리키는 경우 등)는 어떤 파일에도 넣지 않습니다.

## 구조
| 경로 | 내용 |
|---|---|
| `catalog/sources.json` | 수집 대상 목록(기관, 주소, 키 필요 여부, 단위, 상태) |
| `collectors/` | 수집·집계 프로그램(파이썬 표준 라이브러리만) |
| `data/<자료>/` | 결과 파일과 `meta.json`(수집일·원천·건수) |
| `tests/` | 시험(`python3 -m unittest discover -s tests`) |
